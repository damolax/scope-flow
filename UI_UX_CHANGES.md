# ScopeFlow UI/UX refinement

This build keeps the product workflow unchanged and improves how quickly owners and clients can understand and act.

## Owner workspace
- Reduced oversized headings and excessive card height.
- Narrower, calmer navigation with clearer active state.
- Removed the duplicate global header while editing a proposal.
- Made the proposal editor a focused, sticky workspace.
- Added a desktop proposal-table header and denser rows.
- Made row actions secondary until hover or keyboard focus.
- Improved service cards with clearer price hierarchy and edit affordance.
- Uses the business owner's selected currency in the service library.
- Tightened settings forms and spacing.

## Client proposal
- Stronger visual distinction between included and optional services.
- Selected optional services receive a clear active state.
- Improved total-card prominence and decision hierarchy.
- Reduced hero and heading sizes on desktop and mobile.
- Preserved the single clear approval/request action.

## Accessibility and responsiveness
- Added visible keyboard focus states.
- Added accessible labels to icon-only controls.
- Added reduced-motion support.
- Refined mobile spacing, editor actions and sticky total presentation.

No database migration is required for this UI/UX update.
